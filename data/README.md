# Paper D — machine-readable data

All values in Hartree atomic units. `E = E_r - i*Gamma/2`; `Gamma` is the
**full** width throughout (the literature-comparison table quotes `Gamma/2`
because Yu–Ho and Lin–Ho tabulate half-widths).

STATUS: complete for the ground-state map and the n=2 doublet (production
data exported from the solver repository, not re-typed), and complete for
the three supplements a referee is most likely to ask for — the full θc
trajectories, the F = 0.01 field-halving point, and the m = 1 probe. Every
number quoted in the manuscript is now backed by an exported row in this
folder. Pending: persistent DOI (`NEEDS_HUMAN: DOI`).

Sectors: everything here is the m = 0 sector **except** `probe_m1.csv`,
which is an exploratory m = 1 probe and is scoped as such below.

## Files

### `grid_production.csv` — the full 85-point ground-state map
Production grid `F ∈ {0.02,…,0.10} × λ ∈ {0, 0.05, …, 0.80}` (5 × 17 = 85
points). Exported verbatim from the solver output
(`feast-spectral` repo, `exploration/stark2d/d3_map.csv`, generated by
`d3_map_v2.py`); only the column headers were renamed for clarity.

| Column | Meaning |
|---|---|
| `F` | static field (a.u.) |
| `lambda` | Debye screening parameter (a.u.) |
| `Er` | resonance position Re E |
| `Gamma` | full width, `-2 Im E`. Values with `|Gamma| < 1e-10` are below the certified resolution (the manuscript reports them as `< 1e-10`) |
| `E_yukawa_F0` | exact F = 0 Yukawa ground bound level at this λ (prediction anchor; used for the field-induced-displacement panel) |
| `theta_spread` | `|E(θc=0.28) − E(θc=0.18)|`, the two-angle rotation-stability spread quoted as the per-point uncertainty estimate |
| `flag` | derived, not solver output: `below_resolution` where `|Gamma| < 1e-10` (3 rows: F = 0.02 at λ = 0, 0.05, 0.10), `resolved` otherwise (82 rows). Recomputed from the `Gamma` column by the same threshold the manuscript uses; it carries no information beyond `Gamma`, and is provided so that plotting scripts need not re-derive the mask |

### `manifold_n2_F0_02.csv` — the n=2, m=0 doublet at F = 0.02
λ from 0 to 0.30 in steps of 0.025. Exported verbatim from
`exploration/stark2d/d3_manifold.csv` (same generator).

| Column | Meaning |
|---|---|
| `component` | `red` = k = −1 (downhill), `blue` = k = +1 (uphill); k is a continuation label of the λ = 0 parabolic limit, not a quantum number |
| `lambda`, `Er`, `Gamma`, `theta_spread` | as above |

### `theta_trajectories.csv` — full θc trajectories for the two worst points
The rotation-angle trajectories behind the Methods statement that two-angle
agreement is a necessary condition only. Seven angles, θc = 0.15 … 0.45 in
steps of 0.05, for the two least favorable points of the paper. Exported
from section S1 of `d4_referee_supplements.py`.

| Column | Meaning |
|---|---|
| `case` | `ground F=0.02 lam=0.80` (the broad ground state) or `blue n=2 F=0.02 lam=0.30` (the positive-energy uphill n = 2 component) |
| `theta_c` | complex-scaling angle (rad) |
| `Er`, `Gamma` | position and full width at that angle |

Summary (recomputed from this file, and the source of the numbers quoted in
the manuscript): the ground state at F = 0.02, λ = 0.80 varies by
**2.21e-9** in `Er` over the whole range θc ∈ [0.15, 0.45] — the
"stationary to 2e-9" of the Methods section. The n = 2 uphill component at
λ = 0.30 varies by **3.76e-5** over the whole range ("residual variation
4e-5"), but the variation collapses to **1.15e-8** once θc ≥ 0.25, which is
the "true plateau for θc ≥ 0.25". Both production angles (0.18, 0.28) lie
inside the sampled range.

### `field_halving_F001.csv` — the F = 0.01 field-halving check
The single off-grid field point behind the Results statement that the
deepening displacement at strong screening is *not* a quadratic
polarizability. Exported from section S3 of `d4_referee_supplements.py`.
F = 0.01 is deliberately outside the production grid (which starts at
F = 0.02), so it appears here rather than in `grid_production.csv`.

| Column | Meaning |
|---|---|
| `case`, `F`, `lambda` | point identification |
| `Er`, `Gamma` | position and full width |
| `shift` | field-induced displacement `Er − E_yukawa_F0` at λ = 0.8 (`E_yukawa_F0 = −0.04470430444424399`) |

The manuscript's factor is the ratio of the two `shift` values:
`0.006193425762279645 / 0.002763946776867497 = 2.2408`, i.e. **2.24**
against the 4 that a quadratic response would give. The F = 0.02 row of
this file reproduces the corresponding `grid_production.csv` row to all
digits, which is the internal consistency check on the export.

### `probe_m1.csv` — the m = 1 exploratory probe (NOT part of the map)
**Scope warning.** Everything else in this folder is m = 0. This file is a
seven-point exploratory probe of the m = 1 (2p, |m| = 1) resonance at the
single field F = 0.02, produced by `d6_m1_probe.py`. It is reported in the
manuscript as a probe, explicitly not as a map, and it has **no independent
literature anchor** — no published value for the m = 1 Stark resonance
under Debye screening exists in this paper's bibliography. Its only
certifications are the exact hydrogenic limits (see
`../reproducibility/README.md`).

| Column | Meaning |
|---|---|
| `m` | angular sector (1 throughout) |
| `F`, `lam` | field and screening (a.u.) |
| `Er`, `Gamma` | position and full width |
| `Eyuk` | exact F = 0 Yukawa 2p level used as the continuation anchor; `nan` where the 2p level has unbound (λ ≥ 0.25) and the anchor is unusable |
| `qual` | two-angle spread `|E(θc=0.28) − E(θc=0.18)|`, as `theta_spread` above |
| `flag` | `resolved` on all seven points |
| `predictor` | how the search window was placed: `field-ramp seed` (λ = 0), `Yukawa anchor` (λ = 0.05–0.20), or `linear extrapolation (2p unbound at F=0)` (λ = 0.25, 0.30 — the two least anchored points) |
| `thetas` | the accepted angle pair; `0.18/0.28` on all seven points, i.e. no retry at 0.30/0.42 was needed |

### `table_anchors.csv`, `table_lit_comparison.csv`, `table_map_subset.csv`
CSV exports of the manuscript's three numerical tables (pure-Stark anchors;
validation against Yu–Ho / Lin–Ho; map subset).
`table_anchors.csv` and `table_lit_comparison.csv` are transcribed from the
LaTeX source. `table_map_subset.csv` is a rounded subset of
`grid_production.csv` and is now **generated by rounding that file**
(`'%.6f'` on `Er`, `'%.3e'` on `Gamma`, `<1e-10` where the width is below
resolution) rather than transcribed, so the two cannot drift apart; all 15
rows were verified to agree with `grid_production.csv` under that rule.

### `settings_production.json`
Production solver settings as stated in the manuscript (basis scale,
channel cutoff, quadrature, rotation angles, certification tolerances).
